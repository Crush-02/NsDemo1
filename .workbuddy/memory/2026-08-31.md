## 诊断：应收已收导入"缴款日期/支付方式"未填入（根因已定位，待修复）
- 症状：金桂家园模板（27 列）导入后缴款金额有值，缴款日期/支付方式为 0 行。
- 根因：App.vue 给 Toolbar 传 `:col-count="18"` → excelIO.readExcelFile 的 maxCol=18 截断数据行到 col0-17；而模板中缴款日期在 col18、支付方式在 col19，解析阶段即被丢弃。buildColumnMapping 表头匹配是成功的（18→14、19→15），数据读不到所以填不进。已收备注(col23)/合同编号(col25) 同样被截断（模板无数据未暴露）。
- 修复方案（已出计划未编码）：readExcelFile 的 maxCol 改为 max(传入值, Excel 实际最大列)；验证 = 模拟断言 tool col14/15 有值行数=133 + npm run dev 导入 + 导出回归 + vue-tsc。
